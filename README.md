# TeamFlow

A polished project-management SaaS portfolio project built with Next.js App Router, React, TypeScript, Tailwind-style utility concepts (custom CSS in this starter), and Lucide icons.

## Included
- Responsive SaaS dashboard
- Sidebar navigation
- Dashboard statistics and activity
- Projects view
- Interactive Kanban task board
- Create-task modal
- Search/filter tasks
- Team directory
- Analytics dashboard
- Settings page
- Mobile responsive layout

## Run locally
1. Install Node.js 18.18+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

This version is intentionally dependency-light and works without a database or API key. The next production phase can add PostgreSQL, authentication, persistence, drag-and-drop, real-time collaboration, and AI task planning.
